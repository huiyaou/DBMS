# AI 使用日志
## 1. 需求分析与数据设计

### 第一轮

- prompt
  > 请阅读需求变更文档，对照现有系统提出可行方案，文件目录和报告主要结构保持基本一致。
- result
  分析题目复用、共享、版本历史、题库和跨问卷统计需求，提出题目身份、题目版本和问卷题目快照的分层设计，保留现有目录和答题流程。

### 第二轮

- prompt
  > 请实现题目和版本的数据结构，兼容现有问卷数据，保证题目更新不会改变已发布问卷的原题。
- result
  新增 questions、question_versions、question_banks 集合，扩展模型、MongoDB 校验和索引。问卷题目记录可选来源标识并保留内容快照，旧问卷无需补齐来源字段，不自动推断旧题之间的关联。

## 2. 常用题目与题库

### 第一轮

- prompt
  > 请支持保存常用题目，并在其他问卷中直接选用，避免重复创建相同题目。
- result
  实现题目创建、查询和选用接口，增加问卷编辑页的保存入口与独立题目编辑页。选入问卷时生成独立的问卷内题目 ID，记录来源版本；必答和跳转由具体问卷配置。

### 第二轮

- prompt
  > 请支持按用户名共享常用题目，使其他用户能够选用，但不能因此查看他人的问卷答案。
- result
  实现题目所有者按用户名共享，受共享者可查看、选用并基于已有版本创建新版本。问卷管理和结果查看仍检查问卷所有权，题目共享不授予他人答卷访问权限。

### 第三轮

- prompt
  > 请实现题库管理，支持创建、重命名、删除题库，以及添加题目、移除题目和切换所选版本。
- result
  实现个人题库及条目管理。每个题库对同一道题保存一个选定版本，再次加入可切换版本；删除题库或移除条目不会删除问卷中已复用的题目。

## 3. 题目版本管理

### 第一轮

- prompt
  > 请让每个题目版本都能作为编辑起点，修改后生成新版本并记录来源，保证旧版本和已发布问卷保持原样。
- result
  实现基于指定 parent_id 创建新版本，各版本独立保存。编辑不会覆盖来源内容，不同问卷可选用不同版本。恢复旧内容统一通过“编辑为新版本”完成，移除单独的恢复按钮。

### 第二轮

- prompt
  > 编辑为新版本时，请将题目标题放在表单最上方并锁定，只允许修改题型、选项和校验条件。
- result
  将标题置顶并设为只读，切换题型时继续保留原标题。后端同时检查新版本标题与来源版本一致，标题变更请求返回 422，不创建版本；新建题目时仍可填写标题。

### 第三轮

- prompt
  > 请优化版本管理界面，在左侧列出 V0、V1、V2 等版本，右侧展示所选版本内容，并提供逐版本删除入口。
- result
  改为左侧版本列表和右侧详情，初版编号为 V0，后续版本顺序编号。右侧展示题型、选项、校验和来源；列表旁及详情区提供按权限显示的删除操作。

### 第四轮

- prompt
  > 已删除版本请直接从界面消失，其他版本的编号、来源关系和问卷引用保持不变。
- result
  前端仅展示未删除版本，删除当前版本后自动选择剩余可用版本，全部删除时显示空状态。后台保留历史文档以解析来源和维护引用，不因隐藏版本重新编号。

## 4. 问卷选题与发布后追加

### 第一轮

- prompt
  > 请允许已发布问卷追加新题，但不能修改其中原有题目；目标问卷已包含同一题目时，不允许重复加入其他版本。
- result
  增加独立追加接口，允许向草稿或已发布问卷末尾加入新题，拒绝同题重复加入及向已关闭问卷追加。使用修订号控制并发更新，保留原题内容、顺序和跳转规则。新增题默认非必答，已有答卷不补题。

### 第二轮

- prompt
  > 点击加入问卷后，请直接选择自己的草稿或已发布问卷，不要求先打开草稿。
- result
  增加目标问卷选择弹窗，展示标题和状态，标记已包含该题的问卷。提交前读取最新修订号，再调用追加接口；题目页和题库页均可直接发起选题。

## 5. 前端交互与跨问卷统计

### 第一轮

- prompt
  > 请优化题目与题库页面，包括侧栏、页面布局、按钮和操作弹窗，使常用题目管理更加清晰。
- result
  将题目和题库分标签展示，补充侧栏选中状态并统一按钮样式。新建与编辑题目使用独立表单，题库管理、共享、选题和统计使用页面弹窗，补充窄屏布局与未保存修改提示。

### 第二轮

- prompt
  > 请支持查看同一道题在多个问卷中的回答情况，区分不同版本，并限制统计结果的访问范围。
- result
  按具体版本汇总当前用户所拥有问卷的答案，分别计算有效回答次数和去重参与人数。选择题统计选项次数，数字题计算平均值，文本和数字答案提供内容展示。跳过题目不计入有效回答，数字 0 正常参与统计，不同版本不自动合并。

## 6. 删除范围与运行问题

### 第一轮

- prompt
  > 删除常用题目时，请移除题目列表中的显示和所有题库中的对应条目，不要删除草稿或已发布问卷中已经复用的题目。
- result
  题目删除采用归档标记，并清理题库中的对应条目，不修改 surveys 或 responses。问卷继续使用原有快照，已有答案和问卷统计保留；重复删除同一有权限对象仍返回成功。

### 第二轮

- prompt
  > 请支持独立删除每个版本，只移除指定版本及题库中引用它的条目，保留其他版本和问卷中的复用内容。
- result
  实现单版本归档删除，按 version_id 清理题库条目。题目所有者可删除任意版本，受共享者只能删除自己创建的版本；界面分别说明整题与单版本删除的范围。

### 第三轮

- prompt
  > 点击删除题目后出现 Not Found，请排查并修复，使题目和版本删除功能正常使用。
- result
  通过运行服务的 OpenAPI 确认旧后端尚未加载两个删除接口。重启对应后端后确认接口已加载、健康检查成功；前端补充接口未加载时的明确提示。排查期间未删除实际用户题目。
